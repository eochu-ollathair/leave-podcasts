# Help someone get Leave the Podcasts working

If a person gives you this project and asks you to set it up, do the setup with them. Read `README.md` and `START_HERE.md` first. The person does not need the original maker's computer, AI, Telegram account or passwords.

1. Use a Mac or Linux computer with Python 3.10 or newer. Run `python3 start.py` from this folder. The starter installs what the program needs and opens its private settings page. There is no tested Windows starter yet; say that plainly.
2. If the person has no Telegram bot, help them create one with BotFather. The starter finds their own chat after they message the bot. Keep their bot code, page key and settings on their computer. Never put them in GitHub or in a public answer.
3. Have them pick podcasts, episodes per show and how many points they want from **each podcast**. Make a preview from real episode speech. For a show covering several subjects, check that its points cover different subjects. If an episode has no written speech, let the computer finish listening; do not call an empty preview a success.
4. If they want reasons and a sceptical reading beneath each podcast, connect an artificial intelligence program they control and use the **Your angle** box. The free version only quotes speech and cannot reliably infer a motive. Mark a guessed motive as a possibility and name the record or direct account that could confirm it.
5. When they ask to send, check that Telegram accepted the message. Sent episodes must disappear from the chosen list and must not appear in later reports. Turn on morning delivery only when they want it, and check that the next scheduled send is actually due.

The working result is a real preview, a private settings page the person can reopen, and a Telegram report when requested. Report any missing speech or service failure plainly.
